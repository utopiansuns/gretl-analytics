# Аналитика для Gretl

**Вставляете вывод Gretl – получаете разбор результатов на русском языке и отчёт Word по ГОСТ 7.32-2017.**

Приложение-спутник для [Gretl](https://gretl.sourceforge.net): модель, тесты, описательную статистику и прогноз можно скопировать из Gretl одним куском. Приложение само разделит текст, узнает каждую часть и напишет разбор в формате учебной работы: смысл коэффициентов в единицах измерения, проверку значимости по t- и F-критериям, выводы по тестам, оценку прогноза и сравнение моделей.

Windows, macOS, Linux. Всё считается на вашем компьютере: данные никуда не отправляются, Gretl не запускается и не изменяется.

---

## Почему ему можно доверять

- **Ни одного выдуманного числа.** Каждое число в тексте взято из вставки или получено из неё по явной формуле (степени свободы, критические значения, доля объяснённой вариации). Встроенная самопроверка сверяет отчёт с реестром фактов и предупреждает о любом неподтверждённом значении.
- **Статистически корректные решения.** Критическое t – для двусторонней проверки H0: β = 0. Незначимым коэффициентам эффект не приписывается. При p > 0,05 гипотеза не отвергается. Прогноз – точечное значение, интервал – мера неопределённости.
- **Учитывается форма модели:** уровни, логарифмы (эластичности и проценты), фиктивные и сезонные переменные, тренд, квадраты, логит и пробит.
- **Связь – не причинность.** Выводы формулируются как статистические закономерности в выборке.

## Что распознаётся

| Вывод Gretl | Что получается в отчёте |
|---|---|
| Описание данных (`имя = описание`) | Таблица переменных, русские названия и единицы |
| Описательная статистика | Диапазоны и средние в единицах измерения, асимметрия, разброс |
| Модели: МНК, ВМНК, логит, пробит и другие | Трактовка коэффициентов, t-критерий, R², F-критерий, статистика Дарбина–Уотсона, сезонные эффекты |
| Тесты | Уайта, Бройша–Пагана, Коэнкера, Бройша–Годфри, ARCH, RESET, Чоу, QLR, CUSUM, нормальность остатков, исключение и добавление переменных, линейные ограничения, VIF, ADF, KPSS, Энгла–Грейнджера, Хаусмана |
| Прогноз | Точечный прогноз и интервал, MAPE, MAE, U Тейла и доли UM, UR, UD |
| Корреляционная матрица | Сила, направление и значимость каждой парной связи |
| Несколько моделей | Сравнение по информационным критериям и скорректированному R² |

Понимает русский и английский интерфейс Gretl, десятичную точку и запятую. Тест и прогноз относятся к ближайшей модели над ними, поэтому вставляйте в порядке «модель, её тесты, прогноз».

## Русские названия переменных

Словарь заполняется сам по вставленному тексту и очищается вместе с ним.

- **Встроенный словарь Gretl.** Около 1 400 переменных из всех учебных наборов, поставляемых с Gretl (Ramanathan, Greene и др.), переведены на русский язык с единицами измерения. Если одно имя в разных наборах значит разное (`C`: потребление или издержки), набор определяется по остальным переменным в тексте.
- **Свои данные.** Название берётся из описания данных, если оно есть во вставке, иначе подсказывается по имени, в том числе производному: `l_price` → «логарифм цены», `sqft_1` → «жилая площадь с лагом 1». Денежные единицы для своих данных не угадываются: валюту и масштаб впишите сами.
- **Склонение.** Достаточно написать «цена дома»: в тексте появятся «цены дома», «цене дома», «ценой дома».
- **Единицы** выбираются из списка или вписываются свои. «0/1» – для признаков «да/нет» (бассейн, пол): текст сравнивает «при наличии… чем при отсутствии».
- **Ваши правки запоминаются** по имени переменной и подставляются при следующей вставке.

## Отчёт Word по ГОСТ 7.32-2017

- Times New Roman 14 pt, полуторный интервал, абзацный отступ 1,25 см, выравнивание по ширине.
- Поля: левое 30 мм, правое 15 мм, верхнее и нижнее 20 мм; номер страницы внизу по центру.
- Разделы с номером без точки («1 Описание данных»), структурные элементы прописными по центру («ОСНОВНЫЕ ВЫВОДЫ», «ЗАКЛЮЧЕНИЕ»).
- «Таблица 1 – …» над таблицей, шапка повторяется на новой странице.
- Формулы по центру с номером у правого поля: (1).
- Перечисления через тире после вводной фразы, «Примечание – …» после материала, к которому оно относится.
- Типографика научного текста: минус «−», степени «3,76·10⁻¹⁷», диапазоны через тире «1962–1994», пробел перед знаком «%» (ГОСТ 8.417).
- Чёрно-белое оформление без заливок.

**Правка прямо в приложении.** Текст, заголовки, ячейки таблиц и основные выводы можно исправлять на листе, как в Word: набирать, стирать, вставлять, ⌘Z / Ctrl+Z отменяет. Enter делит абзац, Backspace в начале абзаца соединяет его с предыдущим. Правки попадают в Word и при копировании, кнопка «Отменить правки» возвращает исходный текст.

Отчёт копируется целиком или по разделам с сохранением оформления. Это основа работы, а не готовая работа: титульного листа, содержания и списка источников в нём нет. Проверьте формулировки перед сдачей.

## Ограничения

- Интерпретация опирается только на вставленный текст: нет строки с F-статистикой – нет и вывода о значимости уравнения.
- Если единица переменной неизвестна, в тексте стоит «ед. изм. X».
- Графики не анализируются.

## Установка

Готовые сборки лежат в разделе **Releases**. Python и библиотеки уже внутри.

| Система | Файл | Первый запуск |
|---|---|---|
| macOS (Apple Silicon, Intel) | `…-macOS-arm64.dmg`, `…-macOS-x86_64.dmg` | Перетащите приложение в «Программы» и откройте правой кнопкой мыши → «Открыть»: приложение не подписано сертификатом Apple |
| Windows 10, 11 | `…-Windows-x64.zip` | Распакуйте и запустите `GretlAnalytics.exe`. Если SmartScreen предупредит: «Подробнее» → «Выполнить в любом случае» |
| Linux | `…-Linux-x64.tar.gz` | Распакуйте и запустите `GretlAnalytics/GretlAnalytics` |

В Windows нужен Microsoft Edge WebView2: он уже есть в Windows 11 и в обновлённой Windows 10.

### Из исходников

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/utopiansuns/gretl-analytics.git
cd gretl-analytics
make install   # .venv и пакет со всеми инструментами
make run       # открыть приложение
```

Без `make`: `python -m venv .venv`, затем `.venv/bin/pip install -e .` и `.venv/bin/gretl-analytics` (в Windows `.venv\Scripts\`).

## Для разработчиков

```
src/gretl_analytics/
  __main__.py, app.py   запуск, окно (pywebview), командная строка
  api.py                методы, которые вызывает интерфейс
  clipboard.py          буфер обмена с оформлением для Word
  storage.py            словарь, правки и последний текст в папке пользователя
  core/                 от текста Gretl до разделов отчёта
    parsing.py            деление вставки на части и извлечение чисел
    analysis.py           сборка отчёта, поиск переменных, самопроверка чисел
    models.py, style.py   трактовка коэффициентов и тексты разделов
    tests_kb.py           гипотезы, решения и последствия для тестов
    sections.py, tables.py  сравнение моделей, заключение, таблицы
    meta.py               названия и единицы переменных, реестр фактов
    gretl_vars.tsv        словарь переменных учебных наборов Gretl
    morph.py              склонение (pymorphy3)
    stats.py              распределения t, F, χ² без внешних библиотек
    fmt.py, ctx.py        форматирование чисел и типографика
  report/               отчёт Word по ГОСТ 7.32-2017 (python-docx)
  ui/                   интерфейс на обычном JavaScript без сборки (типы через JSDoc)
tests/                  pytest и вывод Gretl на учебных наборах
packaging/              сборка PyInstaller, значки, файлы для .dmg
scripts/                тестовые данные и значки
```

```bash
make test       # тесты
make lint       # pyflakes
make package    # сборка для текущей системы (на Mac сразу .dmg)
make icons      # значки из packaging/icons/source.png
make fixtures   # пересоздать английские тестовые данные (нужен Gretl)
make clean      # удалить артефакты сборки
```

Ядро работает и без окна:

```bash
gretl-analytics paste  --text вывод.txt --glossary словарь.json --out out/
gretl-analytics export --result out/result.json --out отчёт.docx --mode full
gretl-analytics doctor
```

**Проверки.** Тесты сверяют разбор текста и формулировки, склонение, отсутствие неподтверждённых чисел, критические значения с `critical()` Gretl, оформление Word по ГОСТ и типографику. Переменная `GRETL_ANALYTICS_SELFTEST=путь/к/выводу.txt` проверяет собранное приложение целиком: окно, вставку, отчёт, оглавление, словарь и сохранение в Word; код выхода 0 означает успех.

**GitHub Actions.** *CI* прогоняет тесты в Windows, macOS и Linux на Python 3.10 и 3.13. *Release* собирает приложения для всех систем: вручную на вкладке Actions или по тегу `v1.0.0`, тогда файлы сразу публикуются в Releases.
