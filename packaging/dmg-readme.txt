Аналитика для Gretl

Установка
1. Перетащите «Аналитика для Gretl» в папку «Программы» (Applications).
2. Первый запуск: щёлкните по приложению правой кнопкой мыши, выберите «Открыть»
   и подтвердите. Это нужно один раз: приложение не подписано сертификатом Apple.

Все расчёты выполняются на этом компьютере, данные никуда не отправляются.
